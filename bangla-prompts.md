# Jan Bangla — small-model preset + Bangla prompts

Source: https://github.com/janhq/jan

## Small-model preset (low-end phones)
- Model: Qwen2.5 / Qwen3 3–4B, Q4_K_M (~2–3 GB)
- RAM: 8 GB minimum for desktop Jan; for mobile use the PWA / lightweight web UI instead
- Local server: http://localhost:1337 (OpenAI-compatible)

## Bangla system prompt (starter)
> তুমি একজন সহায়ক বাংলা AI সহকারী। উত্তর সবসময় পরিষ্কার বাংলায় দাও, ছোট বাক্যে, উদাহরণসহ।
